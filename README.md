# playfi
music app

🎵 PlayFi – Web Music Player

PlayFi is a modern, responsive web-based music player built using HTML, CSS, and JavaScript.
It provides a smooth UI, powerful song controls, real-time search, and an engaging listening experience — all without any backend.

🚀 Features

🎧 Play / Pause / Next / Previous

🔍 Live Song Search

⏱️ Real-time Progress Bar

📥 Download Current Song

🎶 Playlist with Album Art

🖱️ Click-to-Play from List

📱 Responsive Sidebar (Mobile Friendly)

🎛️ Auto-play Next Song

🪩 Animated Disco Visualizer

🎤 Popular Artists Section


▶️ How It Works
🎵 Music Playback

Songs are managed through a JavaScript array (allsongs)

Clicking any song loads it dynamically into the Audio object

Automatically updates:

Song title

Artist

Poster image

Download link

🔍 Search System

Real-time filtering as you type

Click on any search result to instantly play that song

⏱️ Progress Bar

Syncs with audio time updates

Click or drag to seek any part of the song

📱 Responsive Sidebar

Automatically hides on small screens

Tap icon to toggle sidebar
